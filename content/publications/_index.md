Publications are generated from `data/publications.bib` and optional manual polish in `data/publication_overrides.json`. Use:

```bash
python3 scripts/update_publications.py
```

Google Scholar is useful for discovery, but direct scraping is intentionally not part of the default pipeline. See the README for the safer BibTeX, DOI, ORCID, and Crossref workflow.
